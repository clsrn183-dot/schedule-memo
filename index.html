일정메모 ScheduleMemo

Google 캘린더 일정과 메모를 한 화면에서 관리하고, 여러 컴퓨터에서 함께 쓰는 개인용 Windows 앱입니다.

주요 기능

  • Google 캘린더 일정 보기·추가·수정 (월/주/일 보기)
  • 날짜와 태그를 붙일 수 있는 Markdown 메모
  • 메모를 사용자 본인의 Google Drive 에 저장해 데스크톱·노트북 간 자동 동기화
  • Claude(AI)와 연동해 일정·메모 정리 (사용자가 직접 켠 경우에만)

Google 계정 데이터 사용

이 앱은 사용자가 로그인한 Google 계정의 캘린더(일정 표시·편집)와 Drive 중 이 앱이 만든 파일(메모 저장)에만 접근합니다. 모든 처리는 사용자의 컴퓨터에서 이루어지며, 개발자의 서버로 데이터를 보내지 않습니다. 자세한 내용은 개인정보처리방침을 참고하세요.

About (English)

ScheduleMemo is a personal Windows desktop app that shows and edits the user's Google Calendar events and keeps Markdown notes synced through the user's own Google Drive. It runs entirely on the user's computer and does not send data to any developer-operated server. See the Privacy Policy.
